## 🏀 Athlete Tracker

> A full-stack platform designed around athletic performance and workout tracking.

**Built with:**

`React` `JavaScript` `Node.js` `Express` `SQLite` `JWT` `bcrypt` `Recharts` `AI`

### What it includes

- 🔐 Authentication & protected routes
- 🏋️ Workout tracking
- 📈 Performance analytics
- 🏀 Basketball-specific metrics
- 🩹 Injury tracking
- 🤖 AI-powered training planning
- 📊 Data visualization
- 📁 CSV export

**What this project taught me:**

Building a complete application means much more than making the UI — it means connecting frontend, backend, database, authentication, business logic and user experience into one system.
